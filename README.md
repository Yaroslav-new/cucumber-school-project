# Cucumber.js Project

## 📌 Description
This project uses **Cucumber.js** for writing and executing BDD (Behavior Driven Development) tests using JavaScript. The main application logic is in `src/shouty/`, and the tests are located in `features/`.

Link to the official site of cucumber school - https://school.cucumber.io/collections

## 🚀 Installation
Make sure you have **Node.js** (22.12+ or 24+, required by Mocha 12) installed before starting.

```sh
# Install dependencies
npm install
```

## 🏗️ Project Structure
```
/project-root
│── features/                  # Gherkin feature files and step definitions
│   ├── step_definitions/       # Step implementations
│   │   ├── steps.js
│   │   ├── cat_steps.js
│   ├── support/                # Helper utilities and parameters
│   │   ├── person_parameter.js
│   ├── hear_shout.feature      # Cucumber feature file
│   ├── cat.feature             # Gherkin language demo feature
│── src/shouty/                 # Application source code
│   ├── shouty.js               # Main logic file
│   ├── test/
│   │   ├── network.test.js      # Unit tests for Network/Person
│── cucumber.js                 # Cucumber profiles (default, json, html)
│── .gitignore                  # Git ignore file
│── README.md                   # Documentation
│── package.json                # NPM configuration
│── package-lock.json           # Dependency lock file
```
`report.json` and `report.html` are generated by the report scripts and are not committed (see `.gitignore`).

## ▶ Running Tests
```sh
npm test            # Cucumber scenarios (pretty output)
npm run test:unit   # Mocha unit tests for src/shouty
npm run test:all    # Both
```
Or generate reports:
```sh
npm run test:json
npm run test:html
```

## 📝 Notes
- `features/support/` contains custom parameter types (e.g., `{person}`), so support files must be loaded. `cucumber.js` already includes them, so a plain `npx cucumber-js` works too.
- `features/cat.feature` uses the `en-lol` (LOLCAT) language as a Gherkin keyword demo: `OH HAI` = Feature, `MISHUN` = Scenario, `I CAN HAZ` = Given, `WEN` = When, `DEN` = Then.
